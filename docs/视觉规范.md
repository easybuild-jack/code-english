# 1. 组件库

**Naive UI**。

理由：

- 自带完整深色主题（`darkTheme`），切换只需换一个 provider 的 prop，两套主题不会跑偏
- TypeScript 编写，类型完整，和 Vue3 + TS 无缝
- 按需引入，打包体积小，适合 Tauri
- 组件风格克制，没有强烈的品牌色，容易套自己的 token

图标用 **lucide**（`lucide-vue-next`），线性风格，深浅色下都清楚。

不自己造轮子的组件：输入框、下拉、开关、滑块、标签页、列表、弹层、消息提示。只有"翻译结果区"是自定义排版。

# 2. 颜色 token

用 CSS 变量定义在 `:root` 和 `[data-theme="dark"]` 上，Naive UI 的主题覆盖也从这组值取。

| token | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `--bg` | 窗口背景 | `#FFFFFF` | `#1E1F22` |
| `--bg-2` | 输入框、卡片、列表项背景 | `#F6F7F9` | `#2B2D31` |
| `--bg-3` | 悬停态背景 | `#EEF0F3` | `#35373C` |
| `--border` | 分割线、边框 | `#E3E6EA` | `#3A3D42` |
| `--text` | 主文字（翻译、标题） | `#1F2329` | `#E8E8E8` |
| `--text-2` | 次要文字（点词释义、原文） | `#5F6672` | `#A0A4AB` |
| `--text-3` | 弱文字（时间、提示、占位） | `#9AA0A8` | `#6F7480` |
| `--accent` | 主色（按钮、链接、选中态） | `#2F6FED` | `#6EA0FF` |
| `--accent-bg` | 主色浅底（选中项背景） | `#EAF1FE` | `#26334D` |
| `--star` | 已收藏星标 | `#F5A623` | `#F5B942` |
| `--ok` | 成功（已连接） | `#22A06B` | `#3DBE85` |
| `--danger` | 错误、删除 | `#E5484D` | `#F26D72` |

原则：

- 深色不是纯黑，浅色不是纯灰。`#1E1F22` 和 Cursor / JetBrains 深色接近，眼睛来回不刺
- 深色下高亮文字额外提亮到 `#FFE08A`，否则深底上的深文字对比度不够
- 主色只用在需要点击的地方，翻译文字永远是 `--text`，不用彩色

对比度检查（WCAG AA，正文 ≥ 4.5:1）：

| 组合 | 浅色 | 深色 |
|---|---|---|
| `--text` / `--bg` | 15.4:1 | 13.0:1 |
| `--text-2` / `--bg` | 5.9:1 | 7.2:1 |
| `--text` / `--hl-bg` | 13.6:1 | `--hl-text` / `--hl-bg` 9.1:1 |

# 3. 字体与字号

## 字体栈

```css
--font-ui: "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif;
--font-en: "Segoe UI", system-ui, sans-serif;          /* 翻译结果，方案 A */
--font-en-mono: "Cascadia Code", "Consolas", monospace; /* 翻译结果，方案 B，待实测 */
```

翻译结果区用哪套字体是 PRD 待定项。样例 HTML 里可以切换。倾向：**先用方案 A**。无衬线阅读快；等宽的好处是字母一个一个分得清、抄写时不容易漏字母，但整句阅读感差。上手用几天后定。

不引入外部字体文件。系统字体离线可用、零加载、和 Cursor 视觉一致。后续 macOS 版本时在字体栈末尾补 `-apple-system` / `PingFang SC` / `SF Mono` 即可。

## 字号阶梯

| 名称 | 字号 | 行高 | 用途 |
|---|---|---|---|
| `xl` | 18px | 1.65 | 翻译结果（默认"中"字号） |
| `lg` | 16px | 1.5 | 点词卡片英文、页面标题 |
| `md` | 14px | 1.5 | 正文、输入框、列表主文字、按钮 |
| `sm` | 13px | 1.5 | 点词卡片中文释义 |
| `xs` | 12px | 1.4 | 时间、标签、提示、占位 |

"小 / 中 / 大"字号设置缩放整套阶梯（上表为"中"）：

| 档 | `xl` | `lg` | `md` | `sm` | `xs` |
|---|---|---|---|---|---|
| 小 | 16 | 14 | 13 | 12 | 11 |
| 中 | 18 | 16 | 14 | 13 | 12 |
| 大 | 21 | 18 | 16 | 15 | 13 |

翻译结果额外：`letter-spacing: 0.01em`，`font-weight: 500`。字重比正文略高，抄写时更容易看清。

# 4. 间距与形状

## 间距

8px 基准，只用这几个值：`4 / 8 / 12 / 16 / 24`。

| 位置 | 值 |
|---|---|
| 窗口内边距 | 16px |
| 顶栏、底栏高度 | 40px |
| 区块之间（输入区 → 结果区） | 16px |
| 列表项内边距 | 12px 16px |
| 列表项之间 | 0，用 `--border` 1px 分割 |
| 图标与文字间距 | 8px |
| 行内元素间距（星标、喇叭之间） | 4px |

## 圆角

| 元素 | 圆角 |
|---|---|
| 输入框、按钮、下拉 | 6px |
| 卡片、弹层 | 8px |
| 窗口本体 | 8px（与 Windows 11 DWM 圆角一致；由系统裁切，CSS 同值兜底，系统描边关闭） |

## 阴影与边框

- 窗口本体：1px `--border` 圆角边框；关闭 Windows 原生阴影，避免四角露出矩形轮廓
- 窗口内不用阴影，用 `--bg-2` 底色和 `--border` 分割线做层次

## 图标

lucide，统一 16px，描边 1.75。顶栏和结果区右侧的操作图标 18px。颜色默认 `--text-2`，悬停 `--text`，激活（已收藏）`--star`。

# 5. 翻译结果区排版

这是唯一需要专门排版的区域，规则如下。

```
┌────────────────────────────────────────┐
│ 1. Add a global exception handler.     │  xl / 500 / --text
│ 2. Return a unified response format    │  每句一行，序号 --text-3
│    for all endpoints.           🔊  ☆  │  图标右对齐，垂直居中于最后一行
│                                        │
│ ────────────────────────────────────── │  --border，上下各 16px
│                                        │
│ global exception handler          ☆    │  lg / 600 / --text，高亮底色
│ Spring 圈子固定说法，对应              │  sm / --text-2，缩进 0
│ @ControllerAdvice                      │
│                                        │  12px
│ unified response format           ☆    │
│ 统一返回格式                            │
│ 已收藏 · 第 3 次遇到                    │  xs / --text-3
│                                        │
└────────────────────────────────────────┘
```

- 序号：`xs` 字号、`--text-3`、和句子基线对齐、宽 20px、右边距 8px。单句时不显示序号
- 结果区可滚动，滚动条细（6px）、颜色 `--border`，悬停时才显示
- 单句时 `🔊 ☆` 放在句子右侧同一行；多句时放在最后一行右侧

# 6. 状态样式

| 状态 | 样式 |
|---|---|
| 悬停（列表项、按钮） | 背景 `--bg-3`，过渡 120ms |
| 按下 | 缩放 0.98，或背景再深一级 |
| 焦点（键盘） | 2px `--accent` 外描边，圆角随元素 |
| 禁用 | 透明度 0.45 |
| 已收藏 | 星标填充 `--star` |
| 播放中 | 喇叭图标变停止图标，颜色 `--accent` |
| 错误提示 | 文字 `--danger`，前置 lucide `circle-alert` 图标 |
| 骨架屏（翻译中） | 3 条 `--bg-2` 圆角条，宽 100% / 85% / 60%，1.2s 呼吸动画 |

动效只用两种：颜色 / 透明度过渡 120ms，页面切换（翻译 ↔ 历史 / 设置）左右滑动 180ms。不做别的动画。

# 7. 深浅色切换实现约定

- 根节点 `<html data-theme="light|dark">`，所有颜色只通过 CSS 变量取值，组件内不写死颜色
- "跟随系统"用 `prefers-color-scheme` 监听，Tauri 侧也能拿到系统主题事件，两者取其一即可
- Naive UI 的 `NConfigProvider` 的 `theme` 和 `themeOverrides` 从同一组 token 生成，保证组件库颜色和自定义区域一致
- 切换时 `<html>` 加 `transition: background-color 120ms, color 120ms`，避免闪白
