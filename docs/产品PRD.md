# 1. 产品概述

## 一句话

一个常驻桌面右侧的小悬浮窗：我输入中文，它结合我的档案和当前场景给出最符合语境的英文翻译，我看着它把英文手动敲进 Cursor。

## 目标

- 翻译准确、专业、忠实原意，是可以放心抄写的范本
- 悬浮窗不打断开发节奏，唤起、翻译、抄写、收起一气呵成
- 抄写过程中顺手收藏生词，用久了自然形成自己的词库

## 非目标（明确不做）

- 不做一键复制按钮
- 不扩写、不优化 Prompt、不替我思考
- 不做出题、批改、打卡、学习计划
- 不做英译中（遇到看不懂的英文用别的工具）
- 不做多用户、账号、云同步

# 2. 核心使用流程

## 主流程：翻译并抄写

```
1. 在 Cursor 里想说一句话，比如"把这个接口改成分页返回"
2. 按快捷键 / 点托盘图标，悬浮窗出现，光标已在输入框
3. 输入中文，Enter
4. 1~3 秒后显示：
     翻译（大字）
     可点词或划词查询释义
5. 点回 Cursor 对话框，悬浮窗仍置顶可见但不抢焦点
6. 对着翻译一个词一个词敲进 Cursor
7. 敲到 paginated 不认识或觉得值得记，点悬浮窗里这个词 → 弹出释义 → 点 ☆ 收藏
8. 敲完发出去。悬浮窗留在那，等下一句
```

整个流程中我的手只在两个地方：CodeEnglish 的中文输入框，和 Cursor 的对话框。

## 次流程

- **回看**：翻过的句子在历史里，点一下重新显示
- **复习**：翻收藏列表，听发音，把已经记住的标"已掌握"
- **切场景**：要写邮件时把顶部场景切到"职场"，翻译语气跟着变
- **配置**：改档案、换模型、调语速

# 4. 悬浮窗主界面

## 4.1 窗口

| 项 | 规格 |
|---|---|
| 平台 | 一期 Windows 10+。macOS 为后续版本，一期不开发不验证，但技术选择不能阻碍后续扩展到 mac |
| 默认尺寸 | 宽 400px，高 520px，可拉伸，记住上次尺寸 |
| 默认位置 | 屏幕右侧中部，记住上次位置 |
| 置顶 | 默认开启，顶栏图钉可关 |
| 边框 | 无系统标题栏，顶栏可拖动 |
| 焦点 | 置顶时：点击 Cursor 等其他窗口，悬浮窗失焦但不隐藏、不变色变淡（可设失焦透明度） |
| 唤起 | 全局快捷键（默认 `Ctrl+Shift+E`）显示并聚焦到输入框；再按一次隐藏。点托盘图标同效 |
| 隐藏 | 隐藏不等于退出，托盘常驻。`Esc` 隐藏窗口 |
| 启动 | 开机自启（可关），启动后隐藏在托盘 |

文中快捷键以 Windows 的 `Ctrl` 书写。代码中用 `CmdOrCtrl` 定义，后续 macOS 版本自动映射为 `Cmd`，不需要改文档和逻辑。

## 4.2 布局

```
┌─────────────────────────────────────────┐
│ [翻译|Ask] 场景 [工作 ▾]       📌  ⋯     │  顶栏
├─────────────────────────────────────────┤
│                                         │
│  把这个接口改成分页返回                  │  输入区
│                                         │
│                        发送  复制  清除   │
├─────────────────────────────────────────┤
│                                         │
│  Make this endpoint return              │  结果区：翻译
│  paginated results.                  🔊 │
│                                         │
├─────────────────────────────────────────┤
│       翻译        历史        设置         │  底栏
└─────────────────────────────────────────┘
```

## 4.3 顶栏

- **模式切换**（最左，分段控件）：`翻译` / `Ask`，默认「翻译」，每次启动回到「翻译」
  - **翻译**：只做翻译。提示词明确规定：用户发来的任何内容都只是待翻译文本，即使看起来像问题或指令，也不回答、不执行、不评论
  - **Ask**：和英语教练聊英语学习。只回答单词用法、地道说法、语法、发音、纠错、表达差异等英语学习问题；与英语学习无关的问题（写代码、调 Bug、闲聊、其他领域知识、让它翻译整段文字）一律只回一句「这里只聊英语学习相关的问题。」，不解释
  - Ask 多轮对话只在内存里，切回翻译或点「新对话」即清空，不进历史；发送后输入框清空，失败时把问题退回输入框
  - Ask 回答用中文讲解、英文例句保留英文，纯文本不带 Markdown，一般不超过 200 字
- **场景下拉**：前面带「场景」字样，选项 `工作` / `职场` / `日常` / `购物` / `旅行`，启动时取档案里的默认场景（默认「工作」），切换后立即生效。「工作」是核心场景，覆盖写代码与对 AI 编程助手下指令；其余为生活场景，翻译改用对应场景下的地道表达
- **图钉**：置顶开关，默认开
- **菜单（⋯）**：深色 / 浅色切换、字号大小（小 / 中 / 大）、隐藏到托盘

## 4.4 输入区

- 多行文本框，占 3~4 行高度，超出滚动
- 占位文字：`输入中文，Enter 翻译`
- `Enter` 翻译；`Ctrl+Enter` / `Shift+Enter` 换行。中文输入法选词时的 Enter 不触发翻译。若用户把翻译键改成带修饰键的组合，`Enter` 自动回到换行
- 输入框右下角显示 `发送` / `复制` / `清除`：发送执行当前模式的翻译或提问；复制把当前输入内容写入系统剪贴板；清除只清空当前输入框
- 翻译中：输入框只读，右下角显示"翻译中…"；结果区显示脉冲星光、“正在理解语境”及跳动圆点，下方骨架屏保持呼吸
- 翻译完成后输入框保留原文，不清空，方便微调重翻
- 输入框为空时按 `Enter` 无动作
- 上限 500 字，超出提示"太长了，分几句翻"（长文抄写体验差，也不是主要场景）

## 4.5 结果区：翻译

- 翻译是整个窗口里字最大的元素（默认 18px，可在菜单调），行距宽松，等宽或衬线体，便于逐词辨认
- **多句自动分行**：如果翻译包含多个句子，每句单独一行，前面加序号，方便逐句抄

```
1. Add a global exception handler.
2. Return a unified response format for all endpoints.
```

- 右侧一个图标：`🔊` 朗读整句。不提供收藏整句——句子进历史就够了，收藏只收单词和短语
- **点词 / 划词查释义**：
  - 翻译里每个英文单词都可点，点一下在词的下方弹出小卡片：英文 + 词性 + 音标 + 结合本句的中文释义，右侧 `🔊` 朗读、`☆` 收藏、`×` 关闭
  - 音标跟随全局口音设置：选择“美音”显示美式 IPA，选择“英音”显示英式 IPA；切换口音时已打开的卡片立即重新查询
  - 鼠标划选一段（同一句内、不超过 6 个词）松开后同样弹卡片，查的是整个短语
  - 释义来自模型：同时传入职业、技术栈、行业、场景、中文原文和完整英文例句。卡片突出显示“当前语境”下的准确含义，下方列出不适用于本句的其他常见义；例如编程例句中的 `class` 必须突出“类”，其他常见义再列“班级、阶级、等级”
  - 同一个词在同一句里只查一次（内存缓存）
  - 点卡片外、按 `Esc`、切换模式或重新翻译都会关掉卡片；`Esc` 此时只关卡片，不隐藏窗口
- 文字可鼠标选中（不做禁止选择，防偷懒靠自律，不靠技术对抗）
- **没有复制按钮**，右键菜单也不提供复制

## 4.6 结果区：状态

| 状态 | 展示 |
|---|---|
| 初始（无结果） | 结果区灰字："翻译结果显示在这里。对照着敲进对话框，不要复制。" |
| 翻译中 | 结果区显示“正在理解语境”动效和骨架占位，输入框右下"翻译中…" |
| 成功 | 模型的完整 JSON 解析成功后一次性展示最符合当前档案和场景的翻译 |
| 未配置 API Key | 结果区提示"还没配置模型"，附"去设置"按钮 |
| 网络错误 / 超时（15 秒） | 结果区提示"翻译失败：网络超时"，附"重试"按钮，输入框内容保留 |
| 模型返回格式异常 | 尽量展示能解析出的翻译部分；解析不出则显示原始返回文本 + "重试" |
| API Key 无效 / 余额不足 | 提示具体原因，附"去设置" |

## 4.7 底栏

三个文字标签：`翻译` / `历史` / `设置`。收藏暂不提供独立页面；点词卡片仍可把单词和短语写入收藏表，供后续复习功能使用。

# 5. 历史页

## 用途

回看最近翻过的句子。这也是自动积累的练习记录。

## 布局

```
┌─────────────────────────────────────────┐
│ ← 返回翻译            历史      🔍  清空 │
├─────────────────────────────────────────┤
│ 今天                                     │
│  把这个接口改成分页返回                  │
│  Make this endpoint return paginated…   │
│  工作 · DeepSeek · 14:32               │
│ ─────────────────────────────────────── │
│  这个 Service 里的事务没生效，帮我看看   │
│  The transaction in this service isn't… │
│  工作 · DeepSeek · 11:05               │
│                                         │
│ 昨天                                     │
│  ...                                    │
└─────────────────────────────────────────┘
```

## 规则

- 按时间倒序，按天分组
- 每条显示：原文（1 行截断）、翻译（1 行截断）、场景 · 模型 · 时间
- 点击条目：回到翻译页，恢复该次的输入和完整结果（不重新调模型）
- 条目右滑或右键：删除单条
- 搜索：按原文或翻译内容模糊搜
- "清空"需二次确认
- 保留全部历史，不自动清理（个人使用，量不大）

# 6. 收藏数据（暂不提供独立页面）

## 用途

点词或划词卡片中收藏的单词和短语写入本地收藏表；句子不收藏，历史页里有。
一期先积累数据，不在底栏提供收藏入口；后续复习、生词本、统计功能直接使用这张表。

## 布局

```
┌─────────────────────────────────────────┐
│ ← 返回翻译            收藏          🔍   │
├─────────────────────────────────────────┤
│ [全部 10] [单词 7] [短语 3]              │
│ [未掌握] [已掌握]                        │
├─────────────────────────────────────────┤
│  idempotent                     🔊  ✓   │
│  幂等                                    │
│  This method must be idempotent.        │
│  遇到 3 次 · 收藏于 9月8日               │
│ ─────────────────────────────────────── │
│  global exception handler       🔊  ✓   │
│  全局异常处理器（Spring 固定说法）        │
│  Add a global exception handler with…   │
│  遇到 1 次 · 收藏于 9月8日               │
└─────────────────────────────────────────┘
```

## 收藏内容结构

每条收藏包含：

| 字段 | 来源 |
|---|---|
| 类型 | 单词 / 短语，收藏时自动判定（1 个词=单词，多个词=短语），可手动改 |
| 英文 | 收藏的内容 |
| 中文 | 来自点词卡片的语境释义和其他常见义 |
| 领域 | 模型返回或留空，可手动填 |
| 例句 | 收藏时所在的翻译句子 |
| 遇到次数 | 该英文在翻译历史中出现的次数，自动统计 |
| 熟练度 | 未掌握（默认）/ 已掌握 |
| 收藏时间 | 自动 |

## 规则

- 筛选：类型 × 熟练度，两组可叠加
- 每条右侧：`🔊` 朗读、`✓` 标已掌握（再点取消）
- 已掌握的条目默认折叠到"已掌握"筛选里，不占主列表
- 点条目展开：显示完整例句、可编辑中文和领域、删除按钮
- 同一英文重复收藏：不新增，提示"已收藏"，次数 +1
- 排序：默认按收藏时间倒序，可切"按遇到次数"

# 7. 设置页

六个分组，单页滚动，左侧或顶部有分组锚点。

## 7.1 我的档案

| 项 | 控件 | 默认 |

| 职业 | 文本框 | 程序员 |
| 技术栈 | 文本框，逗号分隔 | Java, Spring, 前端 |

- 二期：多个模型时，翻译页顶栏出现模型下拉框；"设为默认"决定启动时用哪个

## 7.3 朗读

一期方案：调用成熟的在线词典发音接口（有道词典 `dict.youdao.com/dictvoice`），把句子或单词作为参数请求音频并播放。手动点击才朗读，不自动播放。已有项目验证过这个方案，稳定、免费、无需部署。

- 单词：`dictvoice?audio=<小写单词>&type=<1 英音 | 2 美音>`，词典发音，原速
- 句子：`dictvoice?audio=<句子>&type=<1|2>&le=eng`，`le=eng` 强制走有道长句英文神经网络语音，连读与语调更自然；播放速率 0.75x，方便逐词听辨和跟读
- 多句按句拆开顺序播放，单句超过 200 字再按逗号拆
- 实测有道只对词库里有的单词和常见短语返回音频，任意句子会返回 500 "returned null audio"。所以句子请求失败时自动退回系统语音（Web Speech API，WebView2 使用 Windows 自带的英语音色，优先 Natural / Online 音色），同样 0.75x，用户不会看到失败提示

| 项 | 控件 | 默认 |
|---|---|---|
| 发音接口 | 下拉：有道 / 其他预设 | 有道 |
| 口音 | 单选：美音 / 英音 | 美音 |
| 试听 | 按钮，读 `This method must be idempotent.` | |

规则：

- 点击翻译右侧 `🔊` 朗读整句；点击点词卡片里的 `🔊` 朗读该词
- 播放中图标变为 `⏹`，再点停止；播放另一条时自动停止上一条
- 词典接口对长文本有长度限制，超过限制时按句拆开逐句请求、顺序播放
- 请求失败时图标短暂变红并提示"朗读失败"，不影响其他功能
- 语速调节、系统语音、云端 TTS 均放二期，视实际需要再定

## 7.4 快捷键

| 失焦时透明度 | 滑块 60%~100% | 100% |

- 深浅色切换立即生效，无需重启
- 顶栏菜单（⋯）里也有一个主题快速切换项，和快捷键 `Ctrl+Shift+T` 同效
- 两套主题都要保证翻译文字与背景对比度足够。抄写时眼睛在 Cursor 和悬浮窗之间来回，Cursor 多为深色，悬浮窗深色更不刺眼，但由用户自选

## 7.6 通用

| 项 | 控件 | 默认 |
|---|---|---|
| 开机自启 | 开关 | 开 |
| 启动后 | 单选：隐藏到托盘 / 显示窗口 | 隐藏到托盘 |
| 数据位置 | 只读路径 + "打开文件夹" | 本机应用数据目录 |
| 导出数据 | 按钮，导出历史和收藏为 JSON | |

## 7.7 后续版本预留（一期不做）

- **macOS 版本**：同一代码库编译 mac 包。一期在技术上不引入 Windows 专属依赖，快捷键用 `CmdOrCtrl`、Key 存储用跨平台的系统钥匙串库、字体用系统字体栈，以便后续直接扩展
- **两台电脑数据同步**：一期数据只存本机 SQLite，不同步。做 mac 版本时再决定方案（同步盘共享数据目录，或导出 / 导入 JSON 合并）。一期的"导出数据"按钮是最低成本的手动搬运手段
- **用户自带 PostgreSQL（待定）**：默认仍使用本地 SQLite；用户可配置自己的标准 PostgreSQL 连接，启用后只读写远程库。目标是兼容国内云数据库、自建数据库以及 Supabase、Neon 等平台，不绑定特定厂商。密码存系统钥匙串，强制 TLS 和低权限账号。远程故障不静默回退本地；本地与远程的数据搬运必须由用户显式触发。该方案目前仅记录，不进入一期开发范围

# 8. 关键设计决策

这些是有意为之的取舍，实现时不要"顺手优化"掉。

| 决策 | 理由 |
|---|---|
| 没有复制按钮，右键菜单也不给复制 | 手动输入是整个工具存在的理由。允许鼠标选中是因为技术对抗没意义，靠自律 |
| 翻译字号是全窗口最大 | 它是抄写的范本，其他所有元素都是配角 |
| 多句自动分行编号 | 逐句抄比对着一整段抄不容易丢行 |
| 输入框翻译后不清空 | 翻得不满意时改两个字重翻，比重新输入省事 |
| 只有一个窗口，不弹新窗 | 悬浮工具的窗口越多越烦。历史、设置都在窗内切换 |
| Enter 翻译，Ctrl+Enter 换行 | 绝大多数输入是一两句，翻译是高频动作，一键到位；换行是低频动作 |
| 失焦不隐藏 | 抄写时焦点一定在 Cursor，悬浮窗此时必须还看得见 |
| 收藏类型自动判定 | 收藏时不想多点一步选类型，判错了再改 |
| 历史不自动清理 | 历史就是练习记录，是积累的一部分 |
| 一期 TTS 用在线词典发音接口，手动点击才读 | 成熟、免费、有项目验证过。发音是辅助，不值得先花钱或折腾本地语音；不自动播放是为了不打断抄写 |
| 深浅色跟随系统，但可手动切 | Cursor 多为深色主题，悬浮窗跟着深色更不刺眼；但白天在浅色 IDE 里用的人也有，留选择 |

# 9. 边界与异常

| 情况 | 处理 |
|---|---|
| 输入的不是中文（纯英文） | 照常发给模型翻译（模型会原样返回或微调），不特殊拦截 |
| 输入包含代码片段 | 提示词里要求代码原样保留，翻译只处理自然语言部分 |
| 输入包含公司敏感信息 | 工具不判断。设置页模型旁提醒："涉及敏感内容请使用本地模型"。一期不接本地模型，先靠自觉 |
| 网络断开 | 翻译按钮可点，失败后提示网络错误并保留输入 |
| 模型返回格式不符合约定 | 尽力解析翻译部分；解析失败显示原始文本 |
| 同一中文短时间重复翻译 | 不缓存，每次都调模型（每次翻译都可能有不同选词，也是学习） |
| 收藏的词在翻译历史里出现次数统计 | 大小写不敏感，整词匹配，每次翻译成功后异步更新 |
| 窗口被拖出屏幕外 | 下次启动检测，超出屏幕则重置到默认位置 |
| 多显示器 | 记住上次所在显示器；该显示器断开则回主屏 |

# 10. 非功能要求

| 项 | 要求 |
|---|---|
| 平台 | 一期 Windows 10+；代码不引入 Windows 专属依赖，为后续 macOS 预留 |
| 唤起响应 | 快捷键按下到窗口可输入 < 200ms |
| 翻译响应 | 取决于模型，超时 15 秒 |
| 内存 | 常驻 < 100MB |
| 数据 | 全部本地 SQLite，位置可查看，可导出 JSON |
| API Key | 通过跨平台钥匙串库存入系统凭据管理器，不明文写盘（后续 mac 自动走 Keychain） |
| 离线 | 历史、设置及已保存的收藏数据可离线用；翻译、点词释义和在线朗读需联网 |
| 主题 | 深浅色切换 < 100ms，无闪烁 |
